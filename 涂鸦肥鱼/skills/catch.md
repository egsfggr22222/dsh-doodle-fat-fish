# catch —— 我自己看一眼当前屏幕

用户授权我可以主动截屏。执行后走的还是 `pencil act` 那条流程，只是**图片来源**变成我自己截的。

---

# 什么时候用

| 情况 | 用不用 |
|---|---|
| 用户明确说「看一下屏幕」「截个图看看」 | 用 |
| 用户问的东西必须看当前桌面才能回答 | 用 |
| 【托盘呼唤】 | 不用 —— 那条路径自带截图，走 `pencil act` |
| 用户发来图片 | 不用 —— 走 `pict act` / `dsh-companion` |
| 只是问问题、不涉及屏幕 | **不用**，别乱截 |

⚠ 这仍然是「允许画」的闸门之外的**另一件事**：截屏 ≠ 画。截完要不要画，还是按 `pencil-act` 开头的准入条件判断。

---

# 怎么做：一条命令

```
find { method: "act" }
```

**不传 `image`**，程序自己截当前屏幕，然后：

``` 
1. 截屏（物理像素，和画板同一坐标系）
2. OCR + UI 在原图上检测
3. 把 OCR 文字、UI 框画到原图上，最后压一层反色坐标网格
4. 输出 act.png
5. 删掉那张截图（原料不留）
```

返回里带 `path`（act.png）、`matches`（差分块）、`texts`、`uis`。

---

# 然后

和 `pencil act` 完全一样：

```
read_image <act.png>               看一眼
→ 从网格读数                        那些数字就是桌面坐标
→ pencil { action:"draw", items }  原样画到屏幕上
```

**不申报 view，不乘系数，不看像素。** 网格上有数字，读到什么发什么。

---

# 产物

| 东西 | 留不留 |
|---|---|
| 自己截的那张原图 | **不留**，act.py 跑完就删 |
| act.png | 留在系统临时目录，会被清理 |
| 屏幕上的标注 | 这就是交付物 |
| 历史 / 归档 | **没有**，不做 |

---

# 禁止

| 禁止 | 原因 |
|---|---|
| 没有明确请求就截屏 | 这是偷看，不能自己决定 |
| 截屏后不分析、直接贴给用户 | 用户要的是结论，不是又一张图 |
| 申报 view / 乘系数 | 网格数字就是坐标 |
| 保存截图或 act.png | 一次性的，用完即弃 |
| 用 `eye` 代替 `find act` | eye 只给画面，没有 OCR/UI/网格，读数不准 |
